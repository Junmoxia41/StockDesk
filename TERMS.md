> usuarios o clientes reales.

## 1. Aceptación de los términos

Al instalar, acceder o utilizar StockDesk, aceptas estos términos de uso.
Si no estás de acuerdo, no debes utilizar la aplicación.

## 2. Descripción del servicio

StockDesk es una aplicación de gestión de negocio (inventario, punto de
venta, finanzas, reportes, usuarios, proveedores, entre otros módulos)
descrita con detalle en `docs/CATALOGO-FUNCIONALIDADES.md`. La aplicación
funciona actualmente como una **aplicación 100% del lado del cliente**, sin
backend propio (ver `PRIVACY.md` para el detalle de tratamiento de datos).

## 3. Naturaleza "tal cual" del software

StockDesk se proporciona "tal cual" y "según disponibilidad". No se
garantiza que:

- el software esté libre de errores;
- todas las funciones descritas en la documentación se comporten de forma
  idéntica en todos los navegadores y dispositivos;
- los datos permanezcan indefinidamente disponibles si el usuario borra los
  datos de su navegador sin haber hecho un backup previo.

## 4. Funciones simuladas o limitadas (transparencia obligatoria)

Algunas funciones de seguridad y notificaciones son simulaciones locales
pensadas para demostrar el flujo de la interfaz, y **no ofrecen protección
real de nivel servidor**. Estas funciones están señaladas explícitamente en
la propia interfaz (insignia "Simulado" o "No implementado") y detalladas en
`docs/PRODUCTION-AUDIT.md` y `docs/SECURITY.md`. El uso de StockDesk implica
la aceptación de esta limitación mientras no se indique lo contrario.

## 5. Responsabilidades del usuario

El usuario es responsable de:

- mantener copias de seguridad periódicas de sus datos (ver
  `docs/BACKUPS.md`);
- la exactitud de los datos que introduce en la aplicación (precios, stock,
  información financiera);
- el uso adecuado de credenciales de acceso si utiliza el módulo
  multiusuario;
- cumplir con la legislación fiscal y comercial de su jurisdicción al usar
  StockDesk para operar su negocio (StockDesk no ofrece asesoría fiscal ni
  contable).
